Next · Inspect memory

Inspect memory

Predict the address of array index 2, then find the third value in both models. Before inserting 15, predict which values will move.

Array-backed list

Consecutive slots

Each slot in this model takes one byte. The list can grow by moving to a larger backing array.

Address = start address + index × bytes per slot

Linked list

Nodes and links

Each node holds a value and the address of the next node. The head points to the first node.

To find index 2, start at the head and follow two links.

Record the address read by the array, the addresses visited by the linked list, and what each model had to change when inserting 15. Use the value display switch to check that the addresses stay the same.

Explain the trade-off. An array can jump straight to a known index. A linked list can insert by changing links once the insertion point is known.

Next · Stack vs queue

Stack vs queue

Step through the same operations on both structures. Predict which value comes out first.

Stack

Last in, first out

Push and pop both happen at the top.

Circular queue

First in, first out

Enqueue at the rear and dequeue from the front. The next write wraps to the first slot when there is room.

Which value comes out first?

Record the first value removed from each structure and explain the difference. When 7 enters the queue, where is it stored, and when will it leave relative to 20?

Watch the queue after the removal. The front moves. Later, a new value uses the freed slot and goes to the back of the queue.

Next · Build your slides

Build your slides

Use the final 15 minutes to make a short presentation in your own words. Copy your trace to get the addresses, results and notes from your work.

Four slides to hand in

  1. Array, list and linked list. Explain what makes a list a list. Sketch how an array-backed list and a linked list reach index 2 or insert 15.
  2. Stack and queue. Show the same three inputs and the first value removed from each. Explain what the top and front markers tell you.
  3. Set and record. Give one example of each from the print system. Show what happens to a duplicate ID and name two fields in a job record.
  4. Your recommendation. Explain how the print system’s structures work together. Use one lab observation to justify a choice, then say what would change if urgent jobs had to go first.

Check that every slide has a concrete example and that your memory sketch distinguishes an address from its value. Submit one presentation with your name on it.
